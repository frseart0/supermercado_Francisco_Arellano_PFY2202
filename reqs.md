# Semana 1
## Descripción de la actividad
En esta primera semana realizarás la actividad individual formativa 1, denominada "Utilizando tecnologías avanzadas de React en sitios web", que consiste en desarrollar un sitio web React que haga uso de React router y permita redirigir al usuario dentro de varias pantallas dentro del mismo frontend siguiendo las indicaciones específicas del caso asignado; compartiendo con el docente el repositorio creado para el trabajo colaborativo utilizando GIT.
## Instrucciones Específicas
1. Deberás desarrollar un sitio web de gestión de inventario para un supermercado utilizando HTML, JavaScript, CSS y React. El proyecto incluirá una página principal que servirá como el home del aplicativo y un menú inferior que permitirá la navegación hacia otras dos páginas adicionales.
2. Desarrolla la información para las dos páginas adicionales escogiendo dos temas de la siguiente lista:
3. Quiénes somos
	- Nuestras tiendas
	- Contáctanos
	- Cómo comprar
4. Preguntas frecuentes
5. Para la navegación del sitio deberás implementar y configurar React Router.
6. Para entregar el desarrollo, deberás disponibilizar en un repositorio de GitHub con el nombre supermercado-nombre-apellido-siglaCurso y compartir la url del repositorio con tu docente.

# Semana 2
## Descripción de la actividad
En esta segunda semana realizarás una actividad individual formativa, llamada "Implementando gestión de estado en componentes frontend con React", que consiste en desarrollar un sitio web React mediante el uso de tecnologías avanzadas de React y frameworks CSS como Tailwind CSS o Material UI, siguiendo las indicaciones específicas del caso asignado; compartiendo con el docente el repositorio creado para el trabajo colaborativo utilizando GIT.
## Instrucciones Específicas
Deberás continuar el desarrollo de la actividad formativa 1, correspondiente a un sitio web de gestión de inventario de un supermercado. En esta ocasión, deberás agregar un nuevo menú que permita navegar a otras dos páginas. Deberás crear una página encargada de ingresar nuevos artículos al inventario del sitio.
Deberás implementar un estado global para almacenar una lista de artículos disponibles. Este estado debe incluir detalles como nombre, marca y tipo de producto. Deberás crear un formulario que permita agregar nuevos artículos al sitio.
También deberás crear una página que liste en una tabla todos los artículos que actualmente están en el inventario.
Finalmente, deberás implementar un framework de CSS para dar estilo al sitio.

# Semana 3

# Descripción de la actividad
En esta tercera semana realizarás una actividad sumativa de manera individual, llamada "Desarrollando sitios web con React avanzado", en la que deberás desarrollar y presentar, a partir del proyecto elaborado en semanas anteriores, un componente frontend, tomando en consideración los requerimientos indicados en el caso y considerando el uso de tecnologías avanzadas de React y frameworks CSS como Tailwind.
# Instrucciones Específicas
Deberás continuar el desarrollo de la actividad formativa 2, correspondiente a un sitio web de gestión de inventario de un supermercado. En esta ocasión, agregarás más funcionalidades a las 2 ya desarrolladas (pantalla para agregar nuevos artículos al inventario y listar todos los artículos disponibles):
- En la pantalla de lista de artículos deberás crear una función que permita filtrar los artículos del inventario según la categoría seleccionada. El filtro debe actualizar dinámicamente el estado sin perder los datos originales del inventario.
- Detalle de artículos: cuando el usuario haga clic en uno de los artículos de la lista, se deberá mostrar el detalle del mismo y el usuario podrá agregarlo al carrito. Estos artículos agregados al carrito deberán restar la cantidad disponible del inventario.
- Carrito de compras: deberás crear una nueva pantalla que liste todos los artículos que el usuario agregó al carrito. En esta pantalla el usuario podrá aumentar o disminuir la cantidad de artículos y de esa manera deberá irse actualizando el inventario general.
Finalmente, deberás continuar utilizando un framework de CSS para dar estilo al sitio.
